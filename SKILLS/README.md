# Folder SKILLS — SIMKEU Kecamatan Candisari 2027

Folder ini berisi definisi peran (role charter) untuk tim pengembangan project SIMKEU.

## Struktur Laporan

```
SIMKEU Lead (simkeu-lead)
├── Backend & Data (simkeu-backend-data)
├── Frontend & UI (simkeu-frontend-ui)
├── Reporting & Notifikasi (simkeu-reporting-notif)
└── DevOps & Infrastruktur (simkeu-devops-infra)
```

**Aturan utama:** Semua sub-skill **melapor ke SIMKEU Lead** dan harus **mengikuti instruksi Lead**. Lead menugaskan, memantau progres, dan memutuskan **Pass / Revise / Reject** sebelum rilis.

## Prioritas Pengerjaan (disetujui Lead)

| Prioritas | Fokus | Pemegang Tugas Utama |
|-----------|-------|----------------------|
| P1 (Tinggi) | CRUD Master Data, Approval Transaksi, Perubahan Pagu (write+approval), Edit/Hapus Transaksi, Manajemen User | Backend & Data |
| P2 (Menengah) | Filter & Pencarian, Visualisasi Dashboard, Export Excel/PDF, Upload Bukti Dukung, Peringatan Pagu Habis, Laporan Bulanan/Tahunan | Frontend & UI / Reporting & Notifikasi |
| P3 (Rendah) | Audit Log, Dark Mode, Multi-Kecamatan, Cetak SPJ, SQLite Fallback | Semua sesuai keahlian |
| Infrastruktur | Docker, CI/CD, Git, Unit Test | DevOps & Infrastruktur |
