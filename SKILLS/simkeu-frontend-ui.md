# Skill: Frontend & UI (simkeu-frontend-ui)

## Keahlian
Streamlit UI/UX, form input, validasi sisi klien, filter data, visualisasi dashboard (chart/grafik), dan tata letak antarmuka pengguna.

## Struktur Laporan
**Melapor ke:** `SIMKEU Lead (simkeu-lead)`  
**Mengikuti instruksi dari:** Lead

## Tugas per Prioritas

### P1 — Tinggi
(Tidak ada tugas utama di fase P1; bersiap mendukung Backend & Data untuk UI approval dan edit transaksi saat diperlukan Lead.)

### P2 — Menengah
1. **Filter & Pencarian Transaksi** — filter berdasarkan tanggal, sub kegiatan, rekening, jenis transaksi, PPTK, dan status approval pada daftar transaksi.
2. **Visualisasi Dashboard** — grafik realisasi per sub kegiatan, tren bulanan, dan distribusi pengelompokan belanja (gunakan `st.bar_chart`, `st.area_chart`, atau `plotly`).
3. **Upload Bukti Dukung SPJ (UI)** — komponen upload file dan pratinjau bukti dukungan di formulir transaksi.
4. **Dark Mode / Tema** — toggle tema gelap/terang untuk kenyamanan penggunaan.

### P3 — Rendah
5. **Multi-Kecamatan (UI)** — antarmuka pemilih kecamatan jika diperluas ke lebih dari satu kecamatan.

## Contoh Laporan ke Lead
```
[Laporan Frontend & UI]
Tugas: Visualisasi Dashboard
Status: Selesai / Belum Selesai
File yang diubah: app.py (bagian Dashboard)
Uji coba: Grafik realisasi per sub kegiatan muncul dengan benar
Keperluan review Lead: Ya / Tidak
```
